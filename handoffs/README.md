# Handoffs

Need a change in someone else's files? Don't edit them. Create `handoffs/<from>_to_<to>_<short-topic>.md` from
the template below, tell the recipient (and Anushka if it touches a contract or gated item), and keep working
with a stub. The recipient sets `Status: DONE` and notes it in their `updates/<name>_update.md`.

```
# Handoff: <from> -> <to>
Date/Time:
Status: OPEN | IN PROGRESS | DONE
Topic:
What I need changed / added:
Exact files or endpoints involved:
Expected input / output (with example):
Why it is needed (which feature depends on it):
Deadline (hour of hackathon):
What I will use as a stub until then:
Gated? (yes/no, if yes Anushka approved: yes/no)
```
